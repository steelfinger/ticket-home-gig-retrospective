# Ticket Home — My Gigs in Retrospective

A personal retrospective of music gigs and festivals attended, presented as a static single-page website.

Features a Leaflet.js map with arcs from Helsinki, a chronological timeline, event photos, YouTube video embeds, and stories from each event.

## Structure

- `index.html` — the entire site (HTML, CSS, JS, data)
- `gigs.md` — master list of all attended events
- `public-data-of-gigs.md` — researched public data (setlists, tour names, venue details)
- `images/` — optimized images served by the website
- `media/` — original photos and videos (not tracked in git)

## Usage

Open `index.html` in a browser. No build step required.
